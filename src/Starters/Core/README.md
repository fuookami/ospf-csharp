# Fuookami.Ospf.Starters.Core

## [zh]

`Fuookami.Ospf.Starters.Core` 是 OSPF (Open-Source Production Scheduling Framework) 的核心入门包。

本包提供生产调度框架的核心建模与求解能力，包括：

- **Core** -- 调度模型核心（变量、约束、目标函数）
- **Math** -- 数学规划基础（线性代数、符号计算）
- **Utils** -- 通用工具集

### 快速开始

```bash
dotnet add package Fuookami.Ospf.Starters.Core
```

### 适用场景

适用于仅需核心建模与数学求解能力、不需要特定领域框架（如装箱、切割、甘特调度）的项目。

---

## [en]

`Fuookami.Ospf.Starters.Core` is the core starter package for OSPF (Open-Source Production Scheduling Framework).

This package provides the core modeling and solving capabilities for production scheduling, including:

- **Core** -- Scheduling model core (variables, constraints, objectives)
- **Math** -- Mathematical programming foundations (linear algebra, symbolic computation)
- **Utils** -- General-purpose utilities

### Quick Start

```bash
dotnet add package Fuookami.Ospf.Starters.Core
```

### Use Cases

Suitable for projects that only need core modeling and math-solving capabilities without domain-specific frameworks (bin packing, cutting stock, Gantt scheduling).
