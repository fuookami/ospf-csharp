# Fuookami.Ospf.Starters.Csp1d

## [zh]

`Fuookami.Ospf.Starters.Csp1d` 是 OSPF (Open-Source Production Scheduling Framework) 的一维切割问题 (1D Cutting Stock Problem) 入门包。

本包提供完整的一维切割问题建模与求解能力，包括：

- **Framework.Csp1d** -- 一维切割领域模型（原料、需求件、切割模式、废料约束）
- **Framework** -- 调度框架（流程编排、启发式引擎、插件系统）
- **Core** -- 调度模型核心
- **Math** -- 数学规划基础
- **Utils** -- 通用工具集

### 快速开始

```bash
dotnet add package Fuookami.Ospf.Starters.Csp1d
```

### 适用场景

适用于一维切割优化场景，例如钢材切割、纸张裁切、管材下料等。

## [en]

`Fuookami.Ospf.Starters.Csp1d` is the 1D Cutting Stock Problem (CSP1D) starter package for OSPF (Open-Source Production Scheduling Framework).

This package provides complete modeling and solving capabilities for 1D cutting stock problems, including:

- **Framework.Csp1d** -- 1D cutting stock domain model (stock, demand pieces, cutting patterns, waste constraints)
- **Framework** -- Scheduling framework (workflow orchestration, heuristic engine, plugin system)
- **Core** -- Scheduling model core
- **Math** -- Mathematical programming foundations
- **Utils** -- General-purpose utilities

### Quick Start

```bash
dotnet add package Fuookami.Ospf.Starters.Csp1d
```

### Use Cases

Suitable for 1D cutting stock optimization scenarios such as steel cutting, paper trimming, and pipe cutting.
