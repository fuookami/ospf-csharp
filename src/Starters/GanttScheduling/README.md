# Fuookami.Ospf.Starters.GanttScheduling

## [zh]

`Fuookami.Ospf.Starters.GanttScheduling` 是 OSPF (Open-Source Production Scheduling Framework) 的甘特图调度 (Gantt Scheduling) 入门包。

本包提供完整的甘特图调度建模与求解能力，包括：

- **Framework.GanttScheduling** -- 甘特调度领域模型（任务、机器、工序、时间窗口、资源约束）
- **Framework** -- 调度框架（流程编排、启发式引擎、插件系统）
- **Core** -- 调度模型核心
- **Math** -- 数学规划基础
- **Utils** -- 通用工具集

### 快速开始

```bash
dotnet add package Fuookami.Ospf.Starters.GanttScheduling
```

### 适用场景

适用于甘特图调度优化场景，例如车间作业调度、流水线排产、项目进度管理等。

## [en]

`Fuookami.Ospf.Starters.GanttScheduling` is the Gantt Scheduling starter package for OSPF (Open-Source Production Scheduling Framework).

This package provides complete modeling and solving capabilities for Gantt-based scheduling, including:

- **Framework.GanttScheduling** -- Gantt scheduling domain model (tasks, machines, operations, time windows, resource constraints)
- **Framework** -- Scheduling framework (workflow orchestration, heuristic engine, plugin system)
- **Core** -- Scheduling model core
- **Math** -- Mathematical programming foundations
- **Utils** -- General-purpose utilities

### Quick Start

```bash
dotnet add package Fuookami.Ospf.Starters.GanttScheduling
```

### Use Cases

Suitable for Gantt-based scheduling optimization scenarios such as job-shop scheduling, production line planning, and project progress management.
