# Fuookami.Ospf.Starters.Bpp3d

## [zh]

`Fuookami.Ospf.Starters.Bpp3d` 是 OSPF (Open-Source Production Scheduling Framework) 的三维装箱 (3D Bin Packing Problem) 入门包。

本包提供完整的三维装箱问题建模与求解能力，包括：

- **Framework.Bpp3d** -- 三维装箱领域模型（物品、容器、放置约束、旋转策略）
- **Framework** -- 调度框架（流程编排、启发式引擎、插件系统）
- **Core** -- 调度模型核心
- **Math** -- 数学规划基础
- **Utils** -- 通用工具集

### 快速开始

```bash
dotnet add package Fuookami.Ospf.Starters.Bpp3d
```

### 适用场景

适用于三维装箱优化场景，例如集装箱装载、仓储空间规划、物流包装优化等。

## [en]

`Fuookami.Ospf.Starters.Bpp3d` is the 3D Bin Packing Problem (BPP3D) starter package for OSPF (Open-Source Production Scheduling Framework).

This package provides complete modeling and solving capabilities for 3D bin packing problems, including:

- **Framework.Bpp3d** -- 3D bin packing domain model (items, containers, placement constraints, rotation strategies)
- **Framework** -- Scheduling framework (workflow orchestration, heuristic engine, plugin system)
- **Core** -- Scheduling model core
- **Math** -- Mathematical programming foundations
- **Utils** -- General-purpose utilities

### Quick Start

```bash
dotnet add package Fuookami.Ospf.Starters.Bpp3d
```

### Use Cases

Suitable for 3D bin packing optimization scenarios such as container loading, warehouse space planning, and logistics packaging optimization.
