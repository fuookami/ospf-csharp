# Fuookami.Ospf.Starters.Bpp2d

## [zh]

`Fuookami.Ospf.Starters.Bpp2d` 是 OSPF (Open-Source Production Scheduling Framework) 的二维装箱 (2D Bin Packing)入门包。

一条 `dotnet add package` 取代五条手写工程引用，把二维装箱所需的骨架一次装齐。

本包提供以下依赖：

- **Framework.Bpp2d** -- 二维装箱 (2D Bin Packing)领域模型
- **Framework** -- 调度框架（流程编排、启发式引擎、插件系统）
- **Core** -- 调度模型核心
- **Math** -- 数学规划基础
- **Utils** -- 通用工具集

### 快速开始

```bash
dotnet add package Fuookami.Ospf.Starters.Bpp2d
```

## [en]

`Fuookami.Ospf.Starters.Bpp2d` is the OSPF starter package for two-dimensional bin packing.

One `dotnet add package` replaces five hand-written project references and brings everything
two-dimensional bin packing needs.
