# Fuookami.Ospf.Starters.NetworkScheduling

## [zh]

`Fuookami.Ospf.Starters.NetworkScheduling` 是 OSPF 的网络调度 (Network Scheduling)入门包。

一条 `dotnet add package` 取代五条手写工程引用，把网络调度所需的骨架一次装齐：

- **Framework.NetworkScheduling** -- 网络调度 (Network Scheduling)领域模型
- **Framework** -- 调度框架
- **Core** -- 调度模型核心
- **Math** -- 数学规划基础
- **Utils** -- 通用工具集

## [en]

`Fuookami.Ospf.Starters.NetworkScheduling` is the OSPF starter package for network scheduling.

One `dotnet add package` replaces five hand-written project references and brings everything network
scheduling needs.
